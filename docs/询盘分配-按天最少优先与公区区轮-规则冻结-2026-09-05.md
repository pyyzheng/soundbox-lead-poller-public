## 4. 计数规则（人级一本账）

| 项 | 规则 |
|---|---|
| 累计 | **昨日已分 + 今日已分** |
| 切日 | 自然日 `Asia/Shanghai` 00:00 |
| 计入 | 系统自动分配成功（中东/亚洲/公区普通单、代理、查重继承） |
| 不计入 | 人工改派、Case handler 转接、A0 等无效单 |
| 选人 | 在本单**候选人**中选累计最小；并列按花名册序 |
| 代理 +1 后 | 该人累计升高，其他人「缺口」变大，后续普通单继续补给少的人；当天补不齐自然滚到次日 |
| 新人/调入 | 累计对齐当前相关接单人 **max**，避免从 0 狂吃；首日/次日不按巨额待补处理 |
| 历史线索 | **禁止重算、禁止批量改跟进人** |

「待补」仅作理解：`待补 = 候选人中最大累计 − 本人累计`（实现上可直接比累计，不必单独存欠账表）。

## 5. 新线索主流程

```text
新线索（仅新单）
  1) 人工改派非空 → 跟人；不计累计；结束
  2) 查重可继承 → 原业务员；累计 +1；结束
  3) 代理规则命中 → 代理人；累计 +1；
       若国家属公区：公区区指针不动（方案 A）；结束
  4) 国家 ∈ 南美非洲公区 →
       读区指针（中东/亚洲）→ 该区候选人中累计最少 → +1 → 区指针翻转到另一区；结束
  5) 国家 ∈ 中东（非上列已处理代理）→
       候选人 Gigi/Cathy（在岗）→ 累计最少 → +1；结束
  6) 国家 ∈ 亚洲（非上列已处理代理）→
       候选人 Kevin/Rita（在岗）→ 累计最少 → +1；结束
  7) 欧洲及其他子办等 → 仍走现网旧逻辑（本期不改）
```
